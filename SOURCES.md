# Sources

Upstream inspirations for the artifacts in this plugin. Nothing in this repo is a verbatim port, every artifact has been rewritten for personal use. Credits below are courtesy and a memory aid for periodically diff-checking upstream when checking for new ideas.

## Plugin docs

| Artifact | Upstream | Notes |
|----------|----------|-------|
| `plugins/wai/WORKFLOW.md` | own creation | Canonical workflow spine the plugin ships. Read by `/setup` for the marker-block injection into project `CLAUDE.md`. Documents the spine, side paths, invariants, configuration shape (`.claude/wai.json`), subagent surface, and cadence. |
| `plugins/wai/INDEX.md` | own creation | One-line-per-artifact catalog grouped by type (Skills / Agents / Commands). Linted by `scripts/check-index.sh` against the on-disk artifact tree. |
| `plugins/wai/DIFFSCAPE.md` | own, formerly the standalone diffscape plugin's README | Feature reference for the `ds` skill (browser-based code review). Documents the only engine exception in the wai plugin, Node review server, hooks, UI, vendored JS. |
